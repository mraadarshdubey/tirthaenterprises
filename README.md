# Tirtha Enterprises website

Static HTML, CSS and JavaScript. No build step or dependency installation required.

## Preview
Extract the archive and serve this folder with a static web server, such as:

    npx serve .

## Deploy
Upload index.html, the included CSS and JavaScript files, and assets together. Preserve their folder structure.

## Enquiry form
Set LEAD_ENDPOINT in script.js to your lead-receiving endpoint. Until configured, submissions show a failure state and contact alternatives. A backend is not included in this static website package.

## Resources
The page references Google Fonts. Required local fonts, icons, animation libraries and images are included. Hero image source information is in assets/hero-image-source.json.

Design drafts, screenshots, backups and unused asset candidates are excluded.
